# MarkOneFlow

MarkOneFlow is a Chrome extension for reading PDF files and taking notes right next to the document.

## Features

Open and read PDF files directly in Chrome.

Take notes while reading, linked to the document.

Your files and notes stay in your browser.

Pro version (annual subscription) unlocks extra features.
